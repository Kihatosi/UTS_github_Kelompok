# Web Portofolio Kelompok 8

Website portofolio sederhana yang dibuat untuk memenuhi tugas UTS. Halaman ini menampilkan profil anggota kelompok dan informasi mengenai tugas pengelolaan repositori GitHub serta deployment.

## Fitur

- Tampilan halaman web sederhana dan responsif.
- Profil anggota kelompok dalam tiga card horizontal.
- Avatar lingkaran untuk setiap anggota.
- Tautan langsung menuju profil GitHub masing-masing anggota.
- Bagian informasi detail tugas.

## Cara Menjalankan

1. Clone repositori ini:

   ```bash
   git clone https://github.com/Kihatosi/UTS_github_Kelompok.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd UTS_github_Kelompok
   ```

3. Buka file `index.html` menggunakan browser.

Tidak diperlukan instalasi dependensi atau server tambahan untuk menjalankan proyek ini.

## Tujuan Pembelajaran

Proyek ini dibuat untuk mempraktikkan:

- Pembuatan dan pengelolaan repositori GitHub.
- Penggunaan HTML dan CSS untuk membangun halaman web.
